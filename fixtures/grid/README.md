# Grid-intensity snapshot (tier `snapshot`)

Created by `make grid-snapshot` (milestone M9) from the UK Carbon Intensity API — regional data for
London: 7 days of half-hourly history plus a 48-hour forecast. Commit the file so offline runs are
reproducible.
